นับ stock card ที่มี / ไม่มี actor_id		 
SELECT 'F6', 'actor_id NULL',
  COUNT(*)::text
  FROM public.t_stock_cards
  WHERE actor_id IS NULL
UNION ALL
SELECT 'F6', 'actor_id filled',
  COUNT(*)::text
  FROM public.t_stock_cards
  WHERE actor_id IS NOT NULL;
actor_id NULL27,364 (99.95%)
actor_id filled13 (0.05%)
⚠ แทบทุก transaction ไม่รู้ว่า script หรือคนทำ
⚠ สาเหตุ
ทีมออกแบบ column actor_id ไว้เพื่อแยกว่า "transaction นี้ระบบ (script) ทำ" หรือ "คนทำ" แต่โค้ดที่จะเขียนค่าลงมายังไม่ได้พัฒนา ผลคือ 99.95% ของ stock transaction ไม่รู้ว่าใครทำ สรุปพฤติกรรมพนักงานรายคนไม่ได้เลย · 13 rows ที่มีค่าน่าจะเป็นการทดสอบ
🔧 ต้องแก้อย่างไร
พัฒนา feature ให้ populate actor_id จากข้อมูล logged-in user หรือ system script ทุกครั้งที่สร้าง stock transaction ทำงานร่วมกับ is_system_actor (F2) เพื่อแยกประเภทได้ครบ
